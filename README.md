# Portfolio capstone

This repository contains the Frontend AI Engineering capstone. The Next.js app lives in [`frontend`](frontend), including the FE-06 streaming portfolio guide at `/chat`.

- [Screen spec](SCREEN_SPEC.md)
- [Frontend setup and deployment](frontend/README.md)

The frontend uses Next.js App Router, React, TypeScript, and Tailwind CSS. The guide streams Claude responses through an AI SDK route handler. Other portfolio pages remain in progress; `/health` demonstrates a server-rendered fetch.
